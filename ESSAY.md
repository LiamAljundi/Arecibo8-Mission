# How to overcome the lack of choices in interactive fiction games?

*Game design · Interactive fiction · Choice making*
Liam Aljundi, Malmö University (2020)

## Introduction

Interactive fiction (IF) are text-based adventures that players can interact with (Jackson-Mead & Wheeler, 2011, pp. 59-66). IF games existed since the early 1960s, the more popular ones were introduced since the mid 1970s. They are considered less popular nowadays with the existence of more high-end graphic games. However, IF games still have a big community of fans who are highly active on online platforms. I found the techniques and methods used in designing IF games very interesting, not only for designing IF games but for designing games in general. Furthermore, the late Black Mirror movie (Black Mirror: Bandersnatch, 2018) showed that IF can be very successful in movies. One of the phenomena that fascinates me the most about IF is giving the player the freedom to experience the story based on their own choices and interactions. This also made me wonder about the difference between linear stories, IF stories and IF games. More importantly; what makes an IF game different from an IF story?

## Interactive fiction

IF differs from linear fiction by giving the player/reader the freedom to manipulate the environment by interacting with the storyline and challenges along the way (Jackson-Mead & Wheeler, 2011, pp. 1-25). For clarification, IF works are not limited to games, IF stories should be distinguished from IF games. IF stories can serve their purpose without the need for any puzzles or challenges, like any story/novel. However, IF games must contain game elements including challenges. In an article by Sorolla (1996) as mentioned in Jackson-Mead & Wheeler book (2011, pp. 1-24), the author identifies three essential elements to making challenges in games. Those elements are; coordination, chance and problem-solving. There only need to be at least one of these elements in order to make a game challenging.

The player/reader’s interactions create the possibility of multiple endings, which is considered to be a key element of IF works. Sousa (2014) even describes multiple endings as “the simplest form with which to convey the actual effects of a player’s decision” (p. 24). Though, to create a decent IF work, coming to an ending must only be through reasoning that is based on the player/reader’s previous decisions (Jackson-Mead & Wheeler, 2011, pp. 249-260) (Sousa, 2014, pp. 24-25) (Cova & Garcia, 2015, p. 108). In order to achieve this, choices given in IF work should be crafted carefully taking in consideration their meanings and impacts in the story. It is possible to create choices that hold no outcomes or consequences, but that will make the IF work more of a story and less of a game (Jackson-Mead & Wheeler, 2011, pp. 59-66). More significant choices in IF stories add a gamified feel to them as they combine both chance and coordination elements. Though, this is only true when there is enough number of choices in the game, which can be difficult to attain (Sousa, 2014, p.26). Therefore, one has to use alternative ways to overcome this issue. In this essay, it will be argued that overcoming the lack of choices can be achieved through enhancing the problem-solving element and/or by creating choices that are easy to compose (illusion of choice).

## Arecibo 8 game

In order to answer the question of this essay, the Arecibo 8 sci-fi IF game has been created. Arecibo 8 is a one-player space discovery game that combines different IF games’ elements. Besides the story, the game contains illustrations, music and a puzzle (decoder). User tests were held during different stages of development and on the different elements both separately, and combined. The results were evaluated and used in order to answer major and minor questions in this essay. Therefore, there will be references to the Arecibo 8 game whenever it is suitable.

## Puzzles

The engagement of problem-solving through puzzles adds an exciting element to the game. The frequent appearance of that element tolerates the lack of choices in the story. That keeps the story interesting and engaging without the need for creating divergent paths constantly. It is even argued that puzzles are essential to IF games, without them IF can only be considered a story (Jackson-Mead & Wheeler, 2011, pp. 1-24). This is not always true because elements of coordination and chance can transform IF stories to games as well (more on that in the Illusion of Choice section below). Nevertheless, introducing puzzles to interactive fiction adds challenges for players to overcome in order to proceed in the game. This aids the transformation of an IF story from a narrative to a game. That was proven to be true in the majority of user tests of the Arecibo 8 game. Users perceived the game as a sci-fi story before adding a puzzle (the decoder). Adding the decoder succeeded in transforming a sci-fi IF story to a game. Though, in order for the puzzle to be successful, it should be designed carefully to merge with the story’s atmosphere and to have a reasonable level of difficulty. Those two factors were proven to be essential to the decoder’s success.

### Merging with the story

Adding puzzles to IF stories is not enough by itself, the puzzles need to be designed carefully as a part of the game. Jerz (2000) emphasizes the significance of the game’s atmosphere when designing puzzles. Therefore, the theme of the IF story should be considered when making the puzzle, they should not be designed separately and added together without any context. When the puzzle and the story complement each other, they enhance the gameplay experience. The decoder in the Arecibo 8 game is designed to decode alien messages that are played as audio cues and transform it to visual symbols. This fits in the theme of the story, which is space exploration. It would not make much sense if the puzzle was a game of chess, such random challenges breaks the flow of the game (Jerz, 2000). Sorolla (1996) calls such puzzles set-pieces (puzzles out of context) and strongly advices against using them in IF games. He says, “we are in danger of being rudely reminded that the fictional motivation for the game—the efforts of the hero to gather loot, to get back home, to save her family, town, way of life, or universe—is itself only a trivial diversion” (Jackson-Mead & Wheeler, 2011, p. 7). On the other hand, Jerz (2000) and Sorolla (1996) argue that a well fitted, more realistic puzzle is an additional value to the plot.

Creating a puzzle that is relevant to the game’s atmosphere is not enough if there isn’t a smooth transition between the story and the puzzle. The absence of this transition is called “object out of context” by Sorolla (1996), who describes it as damaging to the fictionality of the game (Jackson-Mead & Wheeler, 2011, pp. 1-24). The decoder in the Arecibo 8 game was placed at the point of transition between acts, which is usually a new planet. The player picks up a radio signal from a planet when they approach it, before they are presented with the option of using the decoder. The decoder can break the flow of the game if it is placed somewhere else; during an exploration of a planet or a conversation. Moreover, Taylor (2002) argues that this phenomenon creates inconsistency in the game, which breaks the diegetic immersion (“player’s absorption into the experience of playing the game” (p.13)).

### The level of difficulty

According to Emily Short (2008) there are many factors to consider when it comes to the overall difficulty of a puzzle; the number of solutions, the difficulty of solving the puzzle built-in hints/tutorials. If the overall level of difficulty in an IF game is too hard it will break the intra-diegetic immersion (“experience of the game space through the player-character within that space” (Taylor, 2002, p.13)). If the difficulty is too easy or constant throughout the game, the player won’t feel challenged. Therefore, puzzles require a lot of testing with users from different levels of skills in order to determine their reasonable level of difficulty. This strategy was applied when testing the decoder in the Arecibo 8 game. The decoder was tested separately from the story, with users from different musical and gaming backgrounds. Qualitative research has been held by interviewing users and observing the playtesting sessions. The results were particularly valuable for designing difficulty levels and tutorial for the game.

## Illusion of choice

Creating divergent paths in IF games is not an easy task, it creates many obstacles that one needs to resolve. Nonetheless, it is highly beneficial to provide more choices for the player in IF. This helps transforming the IF from a story to a game by increasing the elements of coordination and chance as mentioned above in the Interactive Fiction section. The three main ways for creating choices in IF games are; foldbacks, branching narratives and innocuous events (Sousa, 2014). Branching narratives are very difficult to create and maintain because each branch is a unique story by its own, which requires a lot of effort and time. That made branching narrative an abandon choice by most IF games’ makers (Sousa, 2014, p.25). Foldbacks are side branches that build on top of the overall story but give the player the freedom to explore the story based on their playstyle. This makes foldbacks ideal as they create multiple storylines within the same story and support the possibility of multiple endings. Innocuous events are choices that lead to the same result, creating the illusion of choice. Even though those choices have no consequence on the plot, but they are proven to be highly effective in engaging the player (Sousa, 2014, p.26).

In the first test of the Arecibo 8 game, only foldbacks were used without relying on any innocuous events. The choices of the player in game determined whether (s)he is an adventurer, an achiever or a loner. Each playing style led to a unique foldback that could lead to one of the main endings. In addition, few extra sub-foldbacks branched out of the main foldbacks and led to dead endings. Testing this model produced similar feedback from users, a near agreement that the game is more of a story. The gaming aspects were not very obvious because even though there were few foldback, but there were not enough choices within those foldbacks. The next step was to add innocuous events to create the illusion of choice and test if it produces better results. However, introducing innocuous events is not as easy as one might think. It is definitely a less time and effort consuming that foldbacks but doing it incorrectly may lead to ruining the game for the user. Thus, one need to be careful to make the illusion of choice invisible to the user.

Creating the illusion of choice may lead to frustrating the user if they discover that their choices have no significance in the game (Hutchison & Mitchell, 2014). This can break the flow of the gameplay and make the user feel cheated. In order to avoid that, every decision in the game should feel meaningful to the user. That should lead the player to think that they have full control of how the story is going when in reality they do not (Tyndale & Ramsoomair, 2016). It is widely argued that the illusion of choice is a powerful and necessary tool in IF games (Tyndale & Ramsoomair, 2016) (Hutchison & Mitchell, 2014) (Sousa, 2014) (Sarian, 2018). As expected, adding innocuous events to the Arecibo 8 game proved to be very effective. Users felt that they had more in control of the events in the game and they felt that their choices are making a difference in the plot.

### Genre advantages

Fiction genres have their own advantages when it comes to creating the illusion of choice. Themes and styles of the genre can be used as guides when creating innocuous events. For example, Despain (2009) states that “While fantasy deals with, “What should I do?” science fiction worries about what should we (read here humankind) do?” (p. 134). This can be used as a guideline in those genres, so that branches in fantasy focuses on individual explorations, while the branches in sci-fi focuses on more collective ones. In addition, one can use the genre to their advantage by designing the story in a way that allows an easy integration of innocuous events. This was used in the Arecibo 8 game by designing the story to be exploration of different planets. Illusion of choice could be created by directing the player to an empty/less eventful planets. Such destinations can be used as a common point that many illusionary choices can arrive to.

Another example of an advantage of the sci-fi genre is adding sci-fi elements. These elements could be planet-statistics display, system checker, ship status…etc. Such elements can be immensely useful in creating the illusion of choice easily (Roggenbuck, 1964). They are usually animations that can be added to the game, which gives the user the illusion that they activated something. All of the elements mentioned above along with few extra ones were used in the Arecibo 8 game and proved to be very effective in adding a more immersive and gamifying feel to the game.

## Conclusion

From what has been argued in this essay; IF games and IF stories are not the same. IF games need to have challenges presented by either problem-solving elements (puzzles) or elements of coordination and chance (more choices in the game). Overcoming the lack of choices in interactive fiction games can be done through creating puzzles or through the illusion of choice. Though, in order to create any of those elements, more careful measures should be considered. Puzzles need to be well integrated with the atmosphere of the IF game and their difficulty level needs to be tested repeatedly until reaching a balanced level. The illusion of choice is an essential part of IF games, it can be a very convenient way to adding more choices to the game. However, it needs to be invisible to the player, so they do not feel cheated by recognising that their choices have no consequence on the game.
